      检测阈值

      置信度低于阈值的候选被丢弃；同类框重叠超过 IoU 阈值时只保留得分最高的一个。运行中调整，下一帧生效。

      采集方式

      窗口目标推荐 WGC：只采集该窗口，覆盖层不会进入画面。桌面复制采集整个显示器，覆盖层的框也会被采集。

      接口

      切换后运行中的会话会重新启动。

      呈现与执行

      三项都会让运行中的会话重新启动。

      覆盖层画框
      在目标所在显示器上绘制检测框，鼠标可穿透。
      CUDA Graph
      把推理整体录制为一张图重放，减少每帧的提交开销。
      GPU 实时调度优先级
      与长时间占用 GPU 的程序同时运行时，检测不再被其挤占；对方分到的 GPU 时间会相应减少（实测帧率约降 12%）。

      结果共享

      让其他程序读取每帧检测结果，用于告警、记录或联动。切换后运行中的会话会重新启动。

      发布到共享内存
      写入 Local\NeuralReflex.Results.v1，任意语言均可读取；读取示例见 tools/results/read_results.py。同一时间只有一个进程能发布。
